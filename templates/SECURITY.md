# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/OWNER/REPO/security/advisories/new).
Do not open a public issue, pull request or discussion for a security problem.

Include what you found, how to reproduce it and the commit or version affected. You should get a reply within
a week.

## Scope

In scope:

- The code in this repository, for example input handling, token handling and stored data.
- The GitHub Actions workflows in `.github/workflows/`.

Out of scope:

- Third-party dependencies and hosted services. Report those upstream.

## Supported versions

Only the latest commit on `main` is supported.
